Site Scout — Ireland (demo)

Enter an Eircode or address for a site. This pulls together the same categories a planner, PM, or architect would gather at the scouting stage — geology & subsoil, water table, archaeology & heritage, utilities, and planning context — from Ireland's public data sources.

How this demo works: an Eircode or address is resolved to a full postal address via the Autoaddress API, then that address is geocoded to coordinates, then six categories are queried in parallel against live Irish public data services where an open API exists. Where no open API exists (utility asset maps), the demo prepares a data-request instead of a live layer — this mirrors how a planner would actually obtain that information today.

On coordinate precision (tested, not assumed): Eircodes are precise to individual buildings — a terrace of ten houses with the same street address can have ten different Eircodes. We tested whether Google's Geocoding API could resolve that precision by requesting three genuinely different Eircodes for three different units in the same building block (D09 V2R3, D09 FY51, D09 HW84 — Dublin Airport Business Park). All three came back with the identical coordinate (53.4073652, -6.2381539) and Google's own location_type: APPROXIMATE / type postal_code — confirming Google geocodes an Eircode as a postcode area, not a unique building, the same fundamental limitation as OpenStreetMap Nominatim. The only sources that actually store one coordinate per Eircode are the licensed Eircode Address Database (ECAD) and Autoaddress's GetData/ie_location endpoint (gated to backend servers with an allow-listed IP — confirmed with a direct 401 test). Neither is available to this browser-only demo, so pins here are area-level approximations, flagged as such in the UI after every search.

Sources used in this flow

  1. Eircode / address resolution — Autoaddress Search & Lookup API (text address + Eircode, no coordinates)
  2. Geocoding (Eircode → coordinates) — Google Maps JavaScript API Geocoder, called with the raw Eircode first; falls back to Google on resolved address text, then OpenStreetMap Nominatim
  3. Property boundary — Tailte Éireann Cadastral Parcels (Freehold/Leasehold); legal folio & filed plan via landdirect.ie
  4. Bedrock & subsoil geology — Geological Survey Ireland (GSI), geodata.gov.ie ArcGIS services
  5. Groundwater vulnerability & levels — GSI Groundwater Vulnerability map; gwlevel.ie; EPA groundwater bodies
  6. Flood risk — OPW Flood Maps (floodinfo.ie)
  7. Archaeology — National Monuments Service Sites & Monuments Record (SMR), Historic Environment Viewer
  8. Protected structures / architectural heritage — NIAH, Heritage Maps
  9. Electricity infrastructure — ESB Networks Dial Before You Dig (request-based, dig@esb.ie)
  10. Water & wastewater infrastructure — Uisce Éireann asset data requests (datarequests@water.ie)
  11. Zoning & planning history — MyPlan.ie
  12. Radon risk — EPA Radon Risk Map
